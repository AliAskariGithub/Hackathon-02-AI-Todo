## Prompt

Todo Full-Stack Web Application - Spec 9: Local Kubernetes & AIOps

Target functionality:
- **Containerization:** Containerize the Frontend (Next.js) and Backend (FastAPI) using Docker.
- **AIOps with Gordon:** Use the Docker AI Agent (Gordon) to generate optimized, secure multi-stage Dockerfiles and a `docker-compose.yaml` for local testing.
- **Orchestration:** Deploy the application onto a local **Minikube** cluster.
- **Helm Packaging:** Create a standard Helm Chart structure (`/charts`) including `values.yaml`, `templates/deployment.yaml`, and `templates/service.yaml`.
- **Agentic K8s Ops:** Use `kubectl-ai` for manifest generation and `Kagent` for real-time cluster health analysis and resource optimization.

Focus:
- **Zero-Manual-Coding:** Every file (Dockerfiles, Helm templates, K8s manifests) must be generated by AI agents (Claude Code, Gordon, or kubectl-ai).
- **Service Mesh Connectivity:** Ensure the Frontend container correctly resolves the Backend container via Kubernetes DNS (e.g., `http://backend-service:8000`).
- **Automation:** Use Claude Code's "Agent Skills" to script the sequence of `docker build` -> `minikube image load` -> `helm install`.

Success criteria:
- Both Frontend and Backend pods are `Running` in the Minikube cluster.
- The application is accessible via a Minikube tunnel or NodePort.
- `kagent "analyze the cluster health"` returns a "Healthy" status with optimized resource limits.

Constraints:
- **Local Cluster:** Must run on Minikube with the Docker driver.
- **AI Tools:** Mandatory use of Gordon (Docker), kubectl-ai, and Kagent.
